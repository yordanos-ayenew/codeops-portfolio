# Habesha Eatery Mini-Site

## Requirements
-Create a two-page accessible website:
     -index.html 
     -contact.html
-Use semantic HTML elements
-Add a reservation form on index.html.
-Add a contact form on contact.html.
-Use a shared navigation menu between both pages.
-Include one <h1> on each page.
-Include a hero image.
-Include audio and video.
-Embed a Google Map using an iframe.
-Store supporting files inside the assets/ folder.
-Validate both HTML files using the W3C Validator.
-Ensure the website is operable by keyboard alone.

## Submission Steps
-Place all project files inside the day12 folder.
-Test navigation between both pages.
-Validate both HTML files using the W3C Validator.
-Push the project to the GitHub repository.
